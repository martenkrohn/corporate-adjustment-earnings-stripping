# Bibliographic records

`references.bib` combines the citation records supplied in the original literature folders. The thesis PDF contains the full reference list, including data-source citations that may not have a separate local BibTeX record.

Third-party literature PDFs are excluded from this repository. Use the titles, DOIs, and URLs in the records or the thesis reference list to locate the respective publications. Original folder labels sometimes use a working-paper year; the bibliographic record and thesis reference list supply the publication details used in the thesis.
